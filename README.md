
# Integrator AutoGT500

Integrator AutoGT500 jest prywatną aplikacją desktopową używaną przez właściciela kont Allegro do integracji sprzedaży z systemem magazynowym BaseLinker.

## Zastosowanie

Aplikacja służy do:

- synchronizacji ofert Allegro z produktami w magazynie BaseLinker,
- synchronizacji dostępności produktów,
- zarządzania czasem wysyłki ofert,
- obsługi danych magazynowych dostawców,
- analizy kosztów sprzedaży,
- zarządzania cenami ofert.

Aplikacja jest wykorzystywana wyłącznie na potrzeby własnej działalności sprzedawcy i nie jest publicznie oferowaną usługą.

## Integracja z Allegro

Aplikacja korzysta z oficjalnego Allegro REST API i mechanizmu OAuth 2.0.

Dostęp do kont Allegro jest autoryzowany bezpośrednio przez właściciela konta.
